# Claim Boundaries

Allowed claims are limited by evidence class and the frozen protocol.

- Known-truth accuracy claims require controlled SIMULATED truth or a genuinely
  identified randomized truth source. Public observational case studies are
  EXTERNAL behavior/robustness evidence, not accuracy leaderboards.
- Track A randomized ITT and Track B observational ATT families are never
  merged into one leaderboard or universal-estimator claim.
- “Official GeoX” applies only to installed-package behavior. In 1.0.1 official
  analysis is TBR only; independent SC/SDID results must retain independent
  labels.
- GeoX native design-aware inference and conventional model-native intervals
  are reported separately. Selected nominal intervals are not described as 95%
  post-selection intervals; only end-to-end empirical coverage supports a
  procedure-level reliability statement.
- AWARE uses no protected outcomes/truth/oracle errors. Oracle is scoring-only.
- Monetary values are synthetic and normalized. No claim implies actual revenue,
  production deployment, proprietary data, a live market, or prospective
  validation.
- GPU claims name one physical RTX GPU and measured workloads. There is no
  multi-GPU or distributed-compute evidence. CPU-faster findings are retained.
- Package incompatibility is not evidence that the statistical method fails;
  method execution failure and statistical/scientific failure are separate.
- Null, unfavorable, gated, and abstention results remain in denominators and
  reporting. Complexity receives no presumed benefit.

The final project decision is exactly one of PROMOTE_AWARE,
RETAIN_FIXED_BASELINE, INCONCLUSIVE, or INVALID_PROTOCOL. Promotion requires H1,
H2, all critical guardrails, and integrity audit. No aggregate score offsets a
failed gate. Resume/interview statements may use only audited E14/E15/E18 claims
linked through `reports/CLAIM_LEDGER.md`.
